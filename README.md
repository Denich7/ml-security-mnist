# Классификация рукописных цифр MNIST

## Назначение

Направление: Computer Vision.

Задача: классификация рукописной цифры по изображению.
Вход: изображение 28 × 28 пикселей в оттенках серого.
Выход: класс от 0 до 9.
Потенциальный пользователь: приложение оцифровки форм.

В лабораторной работе №1 подготовлено окружение и проведён
первичный анализ данных. Обучение модели не выполнялось.

## Датасет

MNIST: 60 000 обучающих и 10 000 тестовых изображений.
Количество классов: 10.
Изображение содержит 784 пиксельных значения.

Описание:
https://keras.io/2/api/datasets/mnist/

Архив:
https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz

Фактический размер: reports/dataset-size.txt.
Эталон SHA256: reports/dataset.sha256.

## Лабораторная работа № 2

Первая лабораторная сохранена меткой Git `lab1`.
Работа над второй лабораторной выполняется в ветке `lab2`.

### Модель

Используется SGDClassifier с loss="log_loss".
Вход — изображение MNIST 28 × 28 в оттенках серого.
Предобработка: развёртка в 784 признака, float32, деление на 255.
Основная метрика — macro-F1.

Параметры фиксированы до оценки на тесте.
Официальный тест MNIST сохранён.
Точные пересечения с тестом, повторные обучающие изображения
и противоречивые группы исключаются из обучающего набора.
Обучение и валидация разделяются со стратификацией и seed=42.

### Запуск

Команды выполняются из корня проекта.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lab2.txt

sha256sum -c reports/dataset.sha256

python -m src.lab2 train
python -m src.lab2 evaluate
python -m src.lab2 predict

python -m pytest tests/ -v
python -m bandit -r src/
pip-audit

sha256sum -c metrics/model.sha256
```

Обучение создаёт baseline.json только при его отсутствии.
Повторная оценка записывает evaluation.json и не изменяет baseline.

При воспроизведении уже существующего baseline собственные новые
результаты обучения следует сохранять отдельно, не заменяя эталон
без явного решения.

### Валидация

Числовой вход: NumPy-массив 28 × 28 или пакет (N, 28, 28).
Максимальный размер пакета — 64 изображения.
NaN, Inf, пустые массивы и пиксели вне 0–255 отклоняются.

Файловый вход: bytes с фактическим форматом PNG.
Максимум — 64 КиБ, размер строго 28 × 28, режим L.
Размеры проверяются до полной загрузки пикселей.

Эти проверки не ограничивают память, затраченную вызывающей стороной
на первоначальную загрузку массива или bytes. Ограничение приёма
сетевого запроса будет реализовано на уровне API.

### Безопасность

Jupyter запускается от mluser на 127.0.0.1.
Аутентификация включена; удалённый доступ выполняется через SSH-туннель.
Данные и модель исключены из Git.
Каталоги data и models доступны только владельцу.

Модель сохраняется как числовые массивы NPZ и загружается
с allow_pickle=False после проверки SHA256.
Предобработка хранится в src/model.py и не содержит обучаемых параметров.
