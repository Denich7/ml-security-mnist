# Классификация рукописных цифр MNIST

## Назначение

Направление: Computer Vision.

Задача: классификация рукописной цифры по изображению.
Вход: изображение 28 × 28 пикселей в оттенках серого.
Выход: класс от 0 до 9.
Потенциальный пользователь: приложение оцифровки форм.

В лабораторной работе №1 подготовлено окружение и проведён
первичный анализ данных. Обучение модели не выполнялось.

## Датасет

MNIST: 60 000 обучающих и 10 000 тестовых изображений.
Количество классов: 10.
Изображение содержит 784 пиксельных значения.

Описание:
https://keras.io/2/api/datasets/mnist/

Архив:
https://storage.googleapis.com/tensorflow/tf-keras-datasets/mnist.npz

Фактический размер: reports/dataset-size.txt.
Эталон SHA256: reports/dataset.sha256.

## Структура

- data/ — датасет, исключённый из Git.
- notebooks/ — исследовательский Notebook.
- src/ — исходный код будущей модели.
- models/ — обученные модели, исключённые из Git.
- tests/ — будущие автоматические тесты.
- reports/ — результаты проверок и анализа.
